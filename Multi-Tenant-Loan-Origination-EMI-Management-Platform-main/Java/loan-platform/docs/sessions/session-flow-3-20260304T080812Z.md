## What Was Planned
Implement Flow 3 where borrower submits a loan application, eligibility is checked (credit score, DTI, income, employment, amount range, duplicate active loan), and if eligible the platform calls Mambu simulation three times for tenure variants (`requested`, `requested-12`, `requested+12`).
Persist `loan_applications`, `loan_offers`, and `loan_state_history`, trigger `SUBMIT` lifecycle event, return offers with 48-hour expiry, and allow borrower to select one offer to hand off to Flow 4.
