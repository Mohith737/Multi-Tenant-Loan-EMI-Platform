  - Tenant Admin: loan product creation.
- Legacy table `tenant_loan_products` was retained for migration compatibility and replaced by `loan_products` in V4.
- Borrower APIs were additionally normalized to JWT tenant scoping to remove repeated tenant headers and enforce consistent tenant isolation.
